# Project Memory

## Core
Frontend: React + Vite + TypeScript, Tailwind CSS, shadcn/ui. Font: Ramabhadra (Telugu).
Backend: Supabase (headless API mode for Flutter migration). Deployed on Netlify.
Telugu by default, English toggle. No technical jargon.
Farmers need NO login. Voice-first design: picture buttons, TTS narration.
Admin requires login. No "Made with love" attribution in footer.
